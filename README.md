# 🏥 Cabinet Medical Project

Système de gestion intégré pour cabinet médical, développé en Java avec une interface graphique JavaFX.

## ✨ Fonctionnalités

- 👥 **Gestion des Patients** : Ajout, modification, suppression et recherche.
- 👨‍⚕️ **Gestion des Médecins** : Suivi des médecins et leurs spécialités.
- 📅 **Gestion des Rendez-vous** : Planification et suivi des consultations.
- 💊 **Gestion des Traitements** : Suivi des soins et calcul des revenus.
- 📊 **Statistiques** : Tableau de bord avec les indicateurs clés (nombre de patients, revenus, etc.).

## 🛠️ Technologies Utilisées

- **Langage** : Java
- **Interface Graphique** : JavaFX
- **Base de données** : MySQL
- **Connectivité** : JDBC (MySQL Connector)
- **Gestion de projet** : Maven

## ⚙️ Prérequis

- JDK 11 ou supérieur
- MySQL Server 8.0
- Apache Maven
- Git
